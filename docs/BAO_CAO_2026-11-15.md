## 4. Còn thiếu / việc nên làm

1. **Bảo mật:** token bot từng bị dán vào chat 15/11 → `/revoke` trong BotFather nếu chưa làm, dán token mới vào `.env`, `botctl.sh restart`. `/setjoingroups` → Disable.
2. Giá SJC/vàng nhẫn niêm yết tự động (sjc.com.vn Cloudflare 403, XML cũ 404) – chưa có nguồn hợp lệ.
3. Bot Telegram bên thứ ba: cần phiên Telegram client do người dùng tự đăng nhập + danh sách chat nguồn.
4. AI tự động: người dùng tự cài và đăng nhập Claude Code CLI, đặt `[ai] enabled = true`, restart. Đường gọi `claude -p` chưa chạy thử.
5. Máy phải thức lúc 08:15/16:30 (cắm sạc + chặn ngủ khi tắt màn hình – người dùng tự chỉnh).
6. Watchdog báo lỗi độc lập với bot, lịch nghỉ lễ, sao lưu DB – chưa làm.
7. Commit repo (chưa có commit nào).
